# Trading Framework

## Objective

Identify liquid NEPSE setups that have a plausible catalyst and favorable risk/reward over approximately five trading sessions.

## Required fields for every setup

| Field | Requirement |
|---|---|
| Symbol | Listed company/ticker |
| Setup | What the price is doing |
| Entry | Specific zone, not a vague price |
| Target | Primary target; secondary if useful |
| Invalidation | Level/condition that proves the thesis wrong |
| Risk/Reward | Prefer asymmetric setups |
| Catalyst | Why the setup may move now |
| Evidence | Price, volume, sector, disclosures/news |
| Counterpoint | Strongest reason not to take the trade |
| Confidence | Evidence strength, not profit guarantee |

## Scenario framework

### Base case
Most likely path based on current evidence.

### Bull case
What would need to happen for upside acceleration?

### Bear case
What would invalidate the thesis or trigger downside?

## Review discipline

At the end of the holding window, compare the forecast with actual price behavior. Record:

- Entry reached or not
- Target reached or not
- Invalidation reached or not
- Maximum favorable excursion
- Maximum adverse excursion
- Catalyst behaved as expected or not
- Market/sector regime contribution
- What the original analysis missed

Never rewrite an old forecast after seeing the outcome.
